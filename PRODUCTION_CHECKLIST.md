# DivaglamKreation Production Checklist

Use this checklist before marking the Vercel site as production-ready.

## Deployment basics

- [x] Next.js project is set up
- [x] `package.json` includes a `build` script
- [x] Repository is ready to import into Vercel
- [x] Deploy from the `main` branch
- [ ] Confirm latest Vercel production deployment passes successfully
- [ ] Confirm custom domain is connected, if using one
- [ ] Confirm HTTPS is active on the live site

## Homepage readiness

- [x] Homepage has hero section
- [x] Homepage has featured collection section
- [x] Homepage has about/brand story section
- [x] Homepage has blog preview section
- [x] Homepage has Glowlist signup section
- [ ] Replace placeholder product buttons with real Gumroad, Etsy, or shop links
- [ ] Replace placeholder product icons/text with real product images or Canva mockups
- [ ] Confirm all navigation links go to the correct sections or pages
- [ ] Review homepage on mobile, tablet, and desktop

## Shop and product readiness

- [ ] Add real link for 3-Day Mini Reset Journal
- [ ] Add real link for 7-Day Reset Journal
- [ ] Add real link for Seasonal Sticker Pieces
- [ ] Confirm each product link opens correctly
- [ ] Confirm pricing/product delivery is set up on Gumroad, Etsy, or chosen shop platform

## Glowlist / email signup

- [ ] Connect the Glowlist form to an email provider
- [ ] Add form success message or redirect
- [ ] Add form error handling
- [ ] Test signup with a real email address

## Content pages

- [ ] Create dedicated Shop page
- [ ] Create dedicated Blog page
- [ ] Create dedicated About page
- [ ] Create dedicated Contact page
- [ ] Replace blog preview text with real blog post links when posts are ready

## SEO and sharing

- [x] Add basic site title and description metadata
- [ ] Add Open Graph title and description
- [ ] Add social sharing image
- [ ] Add favicon/site icon
- [ ] Confirm page title looks right in browser tab
- [ ] Confirm preview looks good when shared on social platforms

## Brand polish

- [ ] Confirm colors match current DGK brand kit
- [ ] Confirm typography feels soft, clean, and readable
- [ ] Confirm copy matches DGK voice: faith-rooted, gentle, encouraging, and clear
- [ ] Check spacing and layout for a calm, uncluttered feel

## Final launch check

- [ ] Run production build successfully
- [ ] Visit live Vercel production URL
- [ ] Test every button and form
- [ ] Test on phone
- [ ] Test on desktop
- [ ] Fix any broken links or visual issues
- [ ] Mark site ready for launch
