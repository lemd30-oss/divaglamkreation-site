# DGK Website Update Checklist

Use this checklist whenever you update the DivaglamKreation website.

## Main files

- `index.html` — live homepage visitors see on divaglamkreation.com
- `blog.html` — blog page
- `README.md` — project notes and setup documentation
- `package.json` — build settings; do not edit unless intentionally changing site setup

## Update rhythm

1. Edit the correct file.
2. Commit changes to the `main` branch.
3. Go to Vercel.
4. Wait for the deployment to say `Ready / Latest`.
5. Visit the live site.
6. Press `Ctrl + F5` if the browser still shows older wording.

## DGK copy direction

Keep website copy aligned with DivaglamKreation:

- faith-rooted
- soft and clear
- warm but not cluttered
- product-focused
- gentle, reflective, and encouraging
- connected to journals, stickers, reset routines, and seasonal pieces
