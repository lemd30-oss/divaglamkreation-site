# DGK Website Launch Checklist

Use this checklist before each DivaglamKreation website launch or seasonal refresh.

## Website foundation

- [x] Homepage sections are in place
- [x] DGK brand styling is applied
- [x] Shop and product calls to action are visible
- [x] Glowlist signup is included
- [x] About and brand mission content are included
- [x] Blog page is available

## Products and checkout

- [x] 7-Day Gentle Reset Journal is featured
- [x] 3-Day Reset Journal link is connected
- [x] Gentle Morning Reset Pack link is connected
- [ ] Confirm current Gumroad prices
- [ ] Test each Gumroad checkout from mobile and desktop
- [ ] Confirm product images or mockups load correctly

## Quality review

- [x] Review copy for the DGK faith-rooted, gentle tone
- [x] Confirm responsive mobile styles are present
- [ ] Test every navigation and footer link on the live site
- [ ] Check keyboard navigation and visible focus states
- [ ] Check spelling, page titles, and meta descriptions

## Vercel launch

- [ ] Confirm the latest `main` commit deploys successfully
- [ ] Confirm the production deployment says `Ready / Latest`
- [ ] Visit the live domain in a private browser window
- [ ] Refresh cached pages and confirm current copy appears
- [ ] Check Vercel Analytics and Speed Insights after launch traffic begins

## Launch content

- [ ] Create Pinterest launch pins
- [ ] Prepare Instagram and Facebook launch posts
- [ ] Add final captions and links to the content calendar
- [ ] Schedule approved posts in Later
- [ ] Verify the Linkin.bio page contains the current launch links

## Final launch standard

Keep the launch simple, polished, warm, and easy to maintain. Do not delay the launch for optional extras that can be added thoughtfully afterward.
