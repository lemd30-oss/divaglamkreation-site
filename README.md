# DivaglamKreation Site

A soft, faith-rooted website for DivaglamKreation, built with Next.js and ready for Vercel deployment.

## Current structure

- `app/page.tsx` — homepage with hero, featured products, about, blog preview, Glowlist signup, and footer
- `app/layout.tsx` — site metadata and root layout
- `app/globals.css` — DGK-inspired cream, coffee brown, soft gold, and warm neutral styling
- `package.json` — Next.js scripts and dependencies

## Local development

```bash
npm install
npm run dev
```

Then open the local development URL shown in the terminal.

## Deploying on Vercel

1. Import this GitHub repository into Vercel.
2. Use the default Next.js framework settings.
3. Deploy from the `main` branch.
